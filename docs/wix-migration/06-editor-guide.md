# Editing the Site — Guide for Group Members

For Fellowship of the Fervent members maintaining the site after handoff. No
technical knowledge needed, and nothing here requires a developer.

## The golden rule

There are two places to edit, and picking the right one matters:

| To change… | Go to | Why |
|---|---|---|
| This week's gathering | **CMS** | It's a list. Add a row |
| Conference details, RSVPs | **Events** | It's an event |
| Wording, photos, page layout | **Editor** | It's design |

Most week-to-week work is the CMS — and the CMS cannot break the layout. That
is deliberate.

## Updating the weekly schedule

1. Wix Dashboard → **CMS** → `Gatherings`
2. **+ Add Item**
3. Fill in date, location, presenter. Leave presenter blank for "to be announced"
4. Close it — the website updates itself

Past dates disappear on their own. You never need to delete old rows, and you
never need to open the Editor.

## Adding a gathering location

CMS → `Locations` → **+ Add Item**. Fill in the address properly and the map on
the site works automatically.

## Managing the conference

Dashboard → **Events**. From here you can edit details, see who has RSVP'd, and
email attendees. Changes appear on the site immediately.

## Changing wording or photos

1. Open the **Editor**
2. Double-click any text to edit it
3. Click an image, then **Change Image** to swap it
4. **Publish** when you're done — nothing is live until you publish

### Please avoid

- Dragging elements around — it breaks the mobile layout
- Deleting a section you're unsure about (use Hide instead)
- Editing the mobile view separately unless you mean to

If something looks wrong, the Editor has **Site History** — you can restore an
earlier version.

## Adding a page

Editor → **Pages** → **+ Add Page**. Start from a blank page and copy a section
from an existing one so the styling matches.

## Before you publish

- Look at the mobile view (the phone icon in the Editor)
- Click your new links
- Check any date or time you typed
